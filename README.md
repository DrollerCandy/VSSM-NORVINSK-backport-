# VSSM-NORVINSK-backport-
Stock and Dustcover of the VSSM by NORBINSK_EVANGELION for SPT 4.1~ Requires WTT Common lib 3.x
Put the project source folder (VSSM Backport) into SPT_Runtime\user\mods folder 
run these 2 commands in the terminal of vs code 
1, Set-Location 'F:\SPT4.1\SPT_Runtime\user\mods\VSSM Backport'
2, dotnet build .\VSSM.csproj -c Release
a folder will be created in the mods folder called release, drag and drop the VSSM folder into the mods folder, delete the source and release folder.
